# Enterprise E-Commerce Analytics Platform

End-to-end analytics project using:

- DuckDB
- SQL
- Parquet
- Polars
- Python
- Power BI
- Git & Automation

## Goal

Transform raw e-commerce transaction data into automated business intelligence and actionable insights.

## Architecture

```text
Raw CSV
   ↓
DuckDB
   ↓
SQL Cleaning & Modeling
   ↓
Parquet
   ↓
Polars EDA
   ↓
Visualization
   ↓
Business Insights
   ↓
Power BI Dashboard
   ↓
Automated Pipeline
```
