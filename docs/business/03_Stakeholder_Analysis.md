# 1. Purpose

The purpose of this document is to identify all key stakeholders involved in the analytics consulting project and define their information needs, decision-making responsibilities, and expected analytical outputs.

Understanding stakeholder expectations ensures that the analytics platform delivers business value through relevant reports, dashboards, and insights.

---

# 2. Stakeholder Overview

| Stakeholder | Role | Primary Responsibility |
|-------------|------|------------------------|
| Executive Board | Strategic | Business growth and strategic decision-making |
| Sales Manager | Operational | Monitor sales performance |
| Marketing Manager | Tactical | Customer acquisition and retention |
| Operations Manager | Operational | Order fulfillment and logistics performance |
| Finance Manager | Tactical | Revenue and payment monitoring |
| Seller Success Manager | Tactical | Seller performance improvement |
| Customer Experience Manager | Tactical | Customer satisfaction and review analysis |
| Data Analytics Team | Technical | Data processing, reporting, and analytics platform maintenance |

---

# 3. Stakeholder Information Needs

| Stakeholder | Information Needed |
|-------------|-------------------|
| Executive Board | Revenue growth, business KPIs, executive summary |
| Sales Manager | Sales trend, best-selling products, top categories |
| Marketing Manager | Customer segmentation, repeat purchase, customer lifetime indicators |
| Operations Manager | Delivery performance, order status, logistics efficiency |
| Finance Manager | Revenue, payment methods, transaction values |
| Seller Success Manager | Seller rankings, sales contribution, seller performance |
| Customer Experience Manager | Customer reviews, ratings, complaint indicators |
| Data Analytics Team | Data quality metrics, pipeline monitoring, transformation status |

# 7. Success Criteria

The analytics platform will be considered successful if each stakeholder can independently access relevant KPIs, monitor business performance, and make informed decisions based on accurate, timely, and consistent analytical outputs.
